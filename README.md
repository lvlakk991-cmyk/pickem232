# S2 Pick'em — Telegram Mini App

Полноценный Telegram **Mini App** (WebApp), визуально повторяющий референс:
тёмная тема, жёлтый бейдж S2, карточка турнира с прогресс-баром и тирами,
список матчей на предсказание, ежедневное задание, топ игроков, статистика —
и **вкладка «Админ» прямо внутри приложения** (видна только вам).

Состоит из трёх частей:
1. **Backend** (`app/main.py`, FastAPI) — REST API + отдаёт статику фронтенда.
2. **Frontend** (`static/`) — HTML/CSS/JS-мини-апп (без сборки, просто статика).
3. **Bot** (`app/bot.py`, aiogram) — по `/start` открывает кнопку, запускающую Mini App.

## ⚠️ Главное условие Telegram Mini App

Telegram открывает Mini App **только по HTTPS**-адресу. Значит backend должен быть
доступен из интернета по HTTPS ещё до того, как бот сможет его открыть. Варианты:
- Быстрый тест: `ngrok http 8000` (или Cloudflare Tunnel) → получите временный https-адрес.
- Продакшн: любой VPS/Railway/Render/Fly.io с доменом и SSL (Let's Encrypt/Caddy/Nginx).

## Установка

```bash
python3 -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
```

Заполните `.env`:
```
BOT_TOKEN=токен_от_BotFather
ADMIN_IDS=ваш_telegram_id        # узнать можно у @userinfobot
DB_PATH=pickem.db
WEBAPP_URL=https://ваш-https-адрес   # см. выше
DEV_MODE=false
```

## Запуск (2 процесса)

**1. Backend** (API + фронтенд):
```bash
uvicorn app.main:app --host 0.0.0.0 --port 8000
```
Откройте `WEBAPP_URL` (или `http://localhost:8000` локально) в браузере — увидите Mini App.

**2. Бот** (в отдельном терминале):
```bash
python3 -m app.bot
```
Напишите боту `/start` → кнопка «🎯 Открыть Pick'em» откроет Mini App внутри Telegram.

## Тестирование в браузере без Telegram

В `.env` поставьте `DEV_MODE=true`, перезапустите backend. В консоли браузера на
странице мини-аппа выполните:
```js
localStorage.setItem('DEV_USER_ID', '111111111')  // ваш ADMIN_IDS для проверки админки
location.reload()
```
Это подставляет заголовок `X-Dev-User-Id` вместо проверки подписи Telegram —
**обязательно верните `DEV_MODE=false` в реальном продакшене**, иначе любой
сможет выдать себя за любого пользователя.

## Что внутри Mini App

**Вкладки снизу** (как на референсе): PICK'EM · ЕЖЕДНЕВКА · ТОП · СТАТЫ (+ АДМИН для админов)

- **Pick'em** — карточка активного турнира с прогресс-баром до тиров
  (BEGINNER 150 / PRO 200 / CHEATER 350 / GOD 500 pts), список матчей.
  Клик по матчу → шторка снизу: выбор победителя → точный счёт → MVP → сохранить.
- **Ежедневка** — задание дня с кнопкой «Выполнить» или «заданий нет».
- **Топ** — рейтинг по очкам, топ-3 выделены золотом/серебром/бронзой.
- **Статы** — очки/точность/предсказания/верные + статус подписки на партнёров.
- **Админ** (только для `ADMIN_IDS`): создание турнира (сразу активный), добавление
  матчей, внесение результата (очки начисляются всем автоматически), управление
  ежедневными заданиями и партнёрскими каналами — всё через формы в самом мини-аппе.

## Система очков
🥇 Победитель +10 · 📊 Точный счёт +15 · 🎖 MVP +20 — меняется в `app/config.py`.

## Про партнёрские каналы

Чтобы backend мог проверять подписку через Telegram Bot API (`getChatMember`),
**бот должен быть администратором** в каждом партнёрском канале. Username канала
указывается в форме «Партнёрский канал» в Админ-вкладке (например `@es1zeman`).

## Структура проекта

```
pickem_miniapp/
├── app/
│   ├── main.py         # FastAPI: весь REST API + раздача static/
│   ├── bot.py            # aiogram-бот: /start → кнопка WebApp
│   ├── database.py       # SQLite (aiosqlite) — турниры/матчи/предсказания/задания
│   ├── auth.py            # проверка подписи Telegram initData (HMAC)
│   ├── telegram_api.py    # проверка подписки на канал через Bot API
│   └── config.py
├── static/
│   ├── index.html          # разметка мини-аппа
│   ├── style.css           # тёмная тема, повторяющая референс
│   └── app.js               # вся логика: вкладки, запросы к API, формы админки
├── requirements.txt
└── .env.example
```

## Возможные доработки
- Push-уведомления пользователям о завершении матча (через бота)
- Несколько турниров одновременно вместо одного активного

- Аватарки пользователей из Telegram вместо иконки-заглушки в топе
